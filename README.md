Worklenz – Project Management System

Overview

Worklenz is a comprehensive project management platform designed to help organizations streamline their workflows, improve team collaboration, and manage resources efficiently.

The system provides an integrated environment for planning projects, managing tasks, tracking working hours, and monitoring team performance through an intuitive user interface.

This repository contains both the frontend and backend implementations of the platform.
## Features

- **Project Planning:** Create, organize, and manage projects while assigning tasks to team members.
- **Task Management:** Break projects into manageable tasks, set deadlines and priorities, and track task progress.
- **Team Collaboration:** Support team communication through file sharing, comments, and collaborative workflows.
- **Time Tracking:** Monitor time spent on individual tasks and projects to improve resource allocation.
- **Reporting & Analytics:** Generate reports on project progress, team workload, and performance metrics.
- **Persian Language Localization:** Localized the user interface into Persian, making the platform accessible to Persian-speaking users and supporting a localized user experience.
